# 警備配置路線マップ作成クエリ

## 背景・問題点・課題
交通誘導警備の工事現場でにて、警備員の資格者配置路線を共有する手段がなく、
口頭での説明に頼っていた為、警備員配置まで時間がかかってしまっていた。
その為誤配置も多発し、無資格者が配置路線へ派遣されてしまい非常にリスクが伴う場面があったり、警備員の入れ替えのため工事ができず2時間弱遅れてしまったりしていた。
さらに内勤や警備員含め正確に資格者指定路線の位置を把握し、説明できる者がかなり限られていたこともあり、問題があると考えた。
以上のことから長期的にリスクを下げ、生産性も上げるルールやツールが必要と判断。
口頭で時間をかけ、不確実な指定路線を確認するやり方ではなく、マップなどで最新の事実情報から一目で指定路線を認識できるツールを作成。


## 解決方法
1. Overpass API(OpenStreetMap)で、神奈川県内の対象路線だけを抽出するクエリを作成
2. overpass turboのエクスポート機能でKMLに変換
3. Googleマイマップにインポートし、関係者に共有


## 開発の進め方
生成AIでクエリのたたき台を作成し、実際の取得結果を地図上で確認しながら、
抽出漏れ・誤抽出を自分で修正した。

## 工夫した点
- 路線番号は `^…$` で完全一致にし、指定外の路線(例：1号線指定で101号線)を除外
- 道路名の全角・半角数字(環状２号/環状2号)や「ヶ/ケ」の表記ゆれを正規表現で吸収

## 結果
同僚・内勤・お客様から「現場がまとまっていて仕事がやりやすい」「現場作業員や警備員を配置する時出動順番を考える手間が短縮でき大変助かる」と評価をいただいた。

## 今後の改善
取得データからKMLを他隊員に渡し、エビデンス情報の調べ方やマップ修正やり方をマニュアル化し教え、長くに渡り使用できるようにする。
